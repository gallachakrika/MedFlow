# MedFlow Adaptive Hospital Command Center

Run:
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

New signature features:
- Adaptive Response Engine
- Explainable patient decision panel
- Next-6-hour demand signal
- What-if crisis controls
- Hospital pressure states: Stable / Watch / High Pressure / Crisis
- Urgency color coding
- Existing scheduling strategies, stress tests, analytics and conflict checks

Synthetic simulation only; not for real clinical decisions.
